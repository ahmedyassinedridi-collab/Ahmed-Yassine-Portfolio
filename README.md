# Ahmed Yassine Dridi — Portfolio

Personal portfolio website for Ahmed Yassine Dridi, Computer Engineering student (Embedded Systems & IoT) based in Tunis, Tunisia.

## ✨ Features

- **Fully responsive** — mobile, tablet, desktop
- **Animated** — scroll reveals, skill bars, counters, typing effect, cursor glow
- **5 sections** — Hero, About, Skills, Projects, Certifications, Contact
- **Zero dependencies** — pure HTML5, CSS3, vanilla JavaScript
- **Vercel-ready** — no build step needed

## 🗂 Structure

```
portfolio/
├── index.html      # Main HTML
├── style.css       # All styles (CSS custom properties, responsive)
├── script.js       # Animations, interactions, form logic
├── photo.png       # Profile photo
└── README.md
```

## 🚀 Deploy to Vercel

1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repo
4. Framework: **Other** (static)
5. Click **Deploy** — done in ~30 seconds!

## 🐙 Push to GitHub

```bash
# In this folder:
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```

## 📬 Contact Form

The form simulates sending by default. To make it real, integrate one of:
- **[Formspree](https://formspree.io)** — free, no backend needed
- **[EmailJS](https://emailjs.com)** — send directly from JS
- **[Web3Forms](https://web3forms.com)** — simple POST API
